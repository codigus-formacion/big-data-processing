# Big Data Processing I

[![SWH](https://archive.softwareheritage.org/badge/swh:1:dir:a0974f23c31e1279864a1e0b38c577e546410856/)](https://archive.softwareheritage.org/swh:1:dir:a0974f23c31e1279864a1e0b38c577e546410856;origin=https://github.com/codigus-formacion/big-data-processing;visit=swh:1:snp:b85e3bc47815261899497322452b0bf7689c4cc1;anchor=swh:1:rev:5d65d2ceecc96c45bbeef0039d662c9462de01fd)

Este repositorio contiene los ejemplos y ejercicios utilizados en la asignatura **Big Data Processing I**, perteneciente al **Máster Universitario en Análisis Deportivo (MUSA)**.  

El objetivo es ofrecer material práctico que permita familiarizarse con diferentes tecnologías para el procesamiento y análisis de grandes volúmenes de datos.

---

## 📂 Contenido

- **`spark/`** — Ejemplos y ejercicios relacionados con **Apache Spark** (RDDs, DataFrames, operaciones sobre DataFrames y ejercicios con datos de fútbol).  
- **`databricks/`** — Ejemplos con **Databricks**: consultas SQL, consultas desde Python (en el workspace y en local), volúmenes, trabajos programados (jobs) y vistas para dashboards.  
- **`influxdb/`** — Ejemplos y ejercicios relacionados con **InfluxDB**, base de datos orientada a series temporales (ejemplos básicos y ejercicios con enunciado y solución).

---

💡 **Nota:** Este material está pensado como apoyo para el aprendizaje práctico de herramientas y tecnologías de procesamiento de datos masivos.
